# Cartografunk · MVP electoral Querétaro

Entrada: `electoral/dashboard_app.py`. App de presentación con boletas locales y un piloto retrospectivo de diputaciones 2024. Los datos son copias derivadas para Querétaro de fuentes INE/IEEQ; no incluye el Parquet nacional CPV ni ZIP de origen.

El CPV 2020 se usa sólo donde la geometría seccional es comparable. Las asociaciones no prueban causalidad ni constituyen pronósticos prospectivos. El reparto de coaliciones es analítico y experimental. Los puntos son sedes de instalación 2024, no domicilios de votantes.

`manifest.json` registra el SHA-256 y tamaño de cada archivo incluido.
